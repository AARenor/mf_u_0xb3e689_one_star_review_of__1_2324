# One-star review of something essential

This is a small program that writes one short text for make.fun's bounty `u-0xb3e689-one-star-review-of-something-essential-c7234629`: a deadpan one-star review, 160 characters or fewer, of an everyday essential — here, gravity, reviewed by someone whose phone fell off the bed at 3 a.m.

The entry text:

```text
One star. My phone fell off the bed at 3 a.m.; gravity landed it exactly where I'd have to get up.
```

Run it with:

```console
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.txt` (no trailing newline) into that folder, creating it if needed, defaults to `/output` when `MAKEFUN_OUTPUT_DIR` is unset, and prints the character count to stderr.
